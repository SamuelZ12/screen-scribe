ScreenScribe Windows V0.1

支持 Windows 10/11 64 位，安装包不需要管理员权限。
安装后从桌面或开始菜单启动，点击任务栏通知区域的取景框图标。

首次使用：在同一面板的设置里填写并保存自己的 Mathpix App ID / App Key。
默认框选快捷键 Ctrl+Shift+L，默认粘贴图片快捷键 Ctrl+Shift+V。
拖动选择公式，松开开始识别；Esc 或鼠标右键取消。
也可导入本地图片，或用 Win+Shift+S 截图后点击粘贴。

OCR / Data / Original：排版预览、源码编辑、原图对照。
支持纯 LaTeX、$...$、$$...$$、equation 和独立公式括号复制。
费曼图须切换支持图像的兼容视觉模型，结果为实验性 TikZ 重建，请核查。

Windows 使用系统 DPAPI 加密凭据；普通设置与历史不保存 API Key。
历史最多50条，默认不把原图写盘。删除凭据和历史在设置中完成。
总剩余是账单快照估算，需手工填写 Billing 数据；每张先扣一次，第五张结束后查询用量校准。

本版没有付费签名证书，安装器可能显示发布者未验证；不要求关闭防病毒、安全启动或系统保护。
操作与测试边界见项目 docs/TEST-RESULTS.md，源码为 MIT 开源许可。
