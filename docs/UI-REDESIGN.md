# 菜单栏 UI 重做与权限误判修复

日期：2026-10-23，Asia/Shanghai。参考：用户提供的 Mathpix Snip 面板截图。

## 修复结果

旧代码在调用截图之前判断 `CGPreflightScreenCaptureAccess()`，false 时直接停止。这只能证明预检查返回 false，不能证明实际截图失败。本版删除该硬门槛及“未给权限”的推断，不重置 TCC、不重新申请授权。

macOS 15.2+ 使用 ScreenScribe 自身的选区覆盖层和 ScreenCaptureKit，不再调用另一个进程执行截图。选区从 AppKit 全局左下原点坐标转换到屏幕显示坐标（主屏高度 − 选区 maxY），保留副屏负坐标。14–15.1 保留系统工具作为兼容路径。成功取图才标记本次访问可用，后续过时预检查不覆盖成功证据。

当前本地构建仍为 ad-hoc 签名，本机未发现可用的代码签名证书。因此不能保证未来每次更换二进制都保持同一 TCC 身份；长期分发应使用稳定开发者签名。本轮新构建的实际 ScreenCaptureKit 截图已成功，不能把历史预检查 false 再当作未授权。

## 单面板交互

- 普通启动只创建状态栏图标，点击显示 NSPopover，没有独立 NSWindow。
- 面板 716×524，白底、浅灰紫边线、窄工具栏，与参考图的层级和密度相近。
- 顶部：框选截图、导入图片、任务/服务、快捷键、历史、记录导航、删除、固定、设置。
- OCR / Data / Original：公式排版、源码编辑、原图切换。
- 四行代码：原始 LaTeX、`$…$`、`$$…$$`、equation；每行复制/编辑/放大。Copy LaTeX 的上下文菜单还可复制 `\[…\]`。
- Copy PNG：复制实际公式预览或原图 PNG；不支持的公式仍能编辑复制源代码。
- 设置与历史在同一面板内切换，点击“返回识别”返回结果。
- 仅展示真实提供的置信分数。没有分数时为中性空条，不编造高置信度。
- 参考图中的订阅、PDF、Word 功能不在本项目范围，没有制作无效按钮。

## 数学预览

KaTeX 0.16.22 完全离线，保留 MIT 许可。WKWebView 使用非持久存储；CSP 禁止网络资源与连接；源码通过 JavaScript arguments 传参，trust=false，限制宏展开和尺寸。不会自动执行 TeX，不支持 TikZ 渲染。未知命令/解析失败显示源码与错误提示。

7. 自动测试共 9 组全部通过：原有 8 组加 ScreenPermissionRegressionTests。新增回归覆盖实际成功优先于过时 preflight；坐标测试覆盖左侧与主屏上方的副屏坐标。
8. 真实 API 识别仍未用个人密钥验证；此次实际成功指截图，不代表线上 OCR 或费曼图准确率。

## 主要修改

`App.swift` 改为状态栏单面板控制器，保留离线 Vision 和原有 Gemini 提示词入口；`SnipPanelView.swift` 负责紧凑 UI；`PhysicsWorkspace.swift` 仅管理结果状态；`LocalMathPreview.swift` 与 `Resources/MathPreview/` 实现离线渲染；截图服务及权限管理移除错误的预检查拦截；既有设置和历史视图改为可嵌入面板。

本轮未增加账户、订阅或云存储，也没有自动重新请求用户的屏幕录制权限。
